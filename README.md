# Jenkins CI/CD Pipeline Demo

## Pipeline Stages
1. Checkout - pulls code from GitHub
2. Build - runs the application
3. Unit Tests - validates code
4. Code Quality - checks standards
5. Package - creates deployable artifact
6. Deploy - deploys to target
7. Smoke Test - verifies deployment

## How to trigger
- Push to main branch (webhook)
- Manual: click Build Now
